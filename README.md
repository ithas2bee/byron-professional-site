# Byron David Lencrerot III | Professional Website

Starter project for an executive-academic personal website with a modern technical influence.

## Stack
- Astro
- TypeScript
- Tailwind CSS
- Static output suitable for common static hosting providers

## Run locally
1. Install Node.js (current LTS recommended).
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Astro.

## Build
Run `npm run build`. The generated static site is written to `dist/`.

## Before public launch
- Verify all biography and career statements.
- Add approved images and screenshots for PresiCompare and Huddle Up.
- Add the final résumé PDF.
- Add a contact method and confirm any public links.
- Configure hosting and a custom domain.
- Review accessibility, mobile behavior, SEO metadata, and privacy.

The source code for PresiCompare and Huddle Up is not included in this repository.


## Website pages

The site includes these routes:
- `/` - Home
- `/about/` - Professional profile and career timeline
- `/projects/` - PresiCompare and Huddle Up
- `/academia/` - Education and academic interests
- `/teaching/` - Teaching interests and future learning resources
- `/resume/` - Web résumé summary
- `/contact/` - Email and LinkedIn

Before publishing, review all biographical details, verify links, and decide whether to add an approved downloadable résumé. Do not add private source repositories to the public site.
