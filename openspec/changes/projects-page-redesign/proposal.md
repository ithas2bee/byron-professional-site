# Proposal: Projects Page Redesign

## Summary
Redesign the Projects page overview and featured-project carousel to match the supplied visual reference: a polished, editorial project showcase with category filters, a prominent featured slide, clear navigation, and browsable project previews.

## User Story
As a visitor to Byron's portfolio, I want to quickly browse and filter projects and understand each featured project's purpose, so I can find relevant work and decide which project details to explore.

## Problem
The current Projects page uses a compact, single-card carousel and places the detailed project case studies below it. The reference proposes a more discoverable overview: category filtering, a large featured project presentation, a labeled project selector, and visible previews of additional work.

## Goals
- Make the Projects page easier to scan and browse.
- Give the active project a strong visual presentation and concise summary.
- Let visitors filter the project set by platform/category.
- Preserve direct paths from project previews to the existing detailed case studies.
- Retain the six existing projects and accurately represent their current status and capabilities.
- Maintain responsive, accessible, and reduced-motion-friendly behavior.

## Out of Scope
- Rewriting or inventing project functionality, status, technologies, or descriptions.
- Replacing the detailed project case studies with carousel content.
- Building new project products or adding backend services.
- Treating visual mockup content as factual product functionality unless confirmed by the project details.

## Reference
Use the user-provided screenshot as the visual target for hierarchy, layout, and interaction. The screenshot is a design reference; actual project copy, assets, and feature claims must remain grounded in the portfolio's real project information.
